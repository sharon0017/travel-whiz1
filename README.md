# Travel Whiz 🌍

Travel Whiz is a peer-to-peer travel platform—akin to a marketplace like Amazon or Flipkart—designed to connect travelers directly with local tourist guides. Our platform empowers local experts to list their services, while giving travelers authentic, personalized experiences with transparent pricing and secure bookings.

## 🚀 How It Works

1. **Discover Local Guides:** Travelers browse through verified local guides and unique destination packages.
2. **Seamless Booking:** Users can select packages, register accounts, and securely check out.
3. **Commission-Based Model:** Travel Whiz acts as the trusted bridge, facilitating the connection between clients and guides while taking a fractional percentage commission on bookings.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
* **Backend:** Spring Boot *(in development)*
* **Version Control:** Git & GitHub
